## 🧩 How I Build

<sub>A simplified look at the architecture behind <b>Hexa AI</b>, the multi-tenant AI calling platform I'm building.</sub>

```mermaid
flowchart LR
    C([📱 Caller]) <-->|voice| T[Twilio]
    T <-->|media stream| API[Nest.js<br/>Call Service]
    API -->|transcript| LLM[OpenAI<br/>Conversation Flow]
    LLM -->|reply text| TTS[ElevenLabs<br/>Voice]
    TTS -->|audio| API
    API --> Q[[Bull Queue]]
    Q --> W[Background<br/>Workers]
    API --> DB[(PostgreSQL)]
    API --> R[(Redis Cache)]
    D[Next.js Dashboard<br/>multi-tenant · RBAC] --> API
```
